# IgANets Special Topic — Poisson Surrogate Modeling

A computational science special-topic project investigating structure-preserving 
neural surrogate models for the Poisson equation on parametric geometries, built 
on the IgANets framework.

**Authors:** Margot van de Klok, Xuan Du (Claire)  
**Supervisor:** Prof. Matthias Möller (TU Delft, Department of Applied Mathematics)  
**Period:** February–June 2026

---

## Problem statement

Given a parametric family of B-spline geometries $\Omega = G([0,1]^2)$, we train 
neural networks to predict the solution of the Poisson equation
$$-\Delta_x u = f \quad \text{on } \Omega, \qquad u|_{\partial \Omega} = 0$$
without invoking an iterative IGA solver at inference time. The right-hand side 
is $f = \sin(\pi x_1)\sin(\pi x_2)$, and geometries are generated by perturbing 
the interior control points of an identity B-spline map with Gaussian noise 
($\sigma = 0.10$).

The project investigates two questions:

1. **Within IgANets**: how should the network output and loss function be 
   structured to best exploit the spline representation?
2. **Across methods**: how does the IgANets approach compare to mainstream 
   neural-operator architectures (specifically the Fourier Neural Operator)?

---

## Dataset

A dataset of **500 geometry–solution pairs** is generated by `docs/generate_data.cxx`. 
Each sample contains:

| Tensor | Shape | Purpose |
|---|---|---|
| `G` | [500, 50] | Geometry control points (5×5×2) |
| `u` | [500, 100] | B-spline solution coefficients (10×10) |
| `u_val` | [500, 100] | Solution evaluated at Greville points |
| `A` | [500, 100, 100] | IGA stiffness matrix (depends on geometry) |
| `b` | [500, 100] | IGA right-hand side (depends on geometry) |
| `G_grid` | [500, 64, 64, 2] | Geometry on regular parameter-domain grid (for FNO) |
| `u_grid` | [500, 64, 64] | Solution on the same grid (for FNO) |

**Dataset health metrics** (verified via `docs/python/verify_dataset.py`):

| Check | Value |
|---|---|
| Sample-to-sample variation in `A` | Non-zero (mean std = 1.17) |
| Trivial baseline (predict mean `u`) — coefficient space | 11.7% |
| Trivial baseline (predict mean `u_grid`) — field space | 9.95% |
| Linear-system residual ‖Au − b‖ (mean) | 5.3 × 10⁻¹¹ |
| Geometry rejection rate (folded geometries) | ~5% |

## Solver modification

The default `EZSolver` in the upstream IgANets framework assembles the 
*parameter-domain* Laplacian, which is independent of the geometry map $G$. 
For this project, two patches were applied to `include/solver/ezsolver.hpp`:

1. **`assembleLhs()`**: replaced the parameter-domain Laplacian 
   $\partial^2_\xi + \partial^2_\eta$ with the leading-order physical-domain 
   pull-back using the inverse metric tensor $g^{kl} = (J_G^{-1} J_G^{-\top})_{kl}$,
   so that $A(G)$ truly depends on the geometry.

2. **Constructor**: added `this->G().from_tensor(geometryMap.as_tensor())` 
   so that the actual perturbed geometry is used during assembly, instead 
   of the framework's default Greville-based identity initialisation.

Solver sanity-check on an identity geometry against the analytical Fourier-series 
reference: relative $L^2$ error = **0.42%**, residual = 0.053%.

## Experiments and results

All experiments share the same 400/100 train/test split. Networks E1–E3 use 
identical architecture (50 → 512 → 512 → 512 → 100, tanh activations) and 
training schedule (Adam, lr = 10⁻³ with 6-segment decay, 30 000 epochs).

### E1 — Coefficient prediction (main proposal)

Predicts B-spline coefficients $\hat{c}_{ij}$ directly. Output lies natively 
in the spline space $V_h$.

| Metric | Value |
|---|---|
| Coefficient-space relative L² | **3.64%** |
| Field-space relative L² | **3.09%** |
| Maximum boundary violation | 1.51 × 10⁻⁴ |
| Trainable parameters | ≈ 580 000 |
| Inference time (M4 CPU) | 0.062 ms |
| Improvement over trivial baseline | 3.2× |

### E2 — Field-value prediction (baseline)

Same architecture as E1, but trained to predict pointwise values at Greville 
collocation points. Removes the spline structural constraint.

| Metric | Value |
|---|---|
| Field-space relative L² | 3.19% |
| Coefficient-space L² (after back-projection) | 3.88% |
| Maximum boundary violation | 2.67 × 10⁻⁴ |

**Finding**: E1 and E2 perform comparably in field-space L² — the Greville 
points are quasi-interpolation nodes for the chosen spline space. The 
structural advantage of E1 emerges in boundary preservation (1.8× better) 
and in its compatibility with E3's residual loss.

### E3 — Loss function ablation

Sweeps the mixing parameter $\alpha$ between supervised and residual losses:
$$\mathcal{L}(\alpha) = \alpha \cdot \frac{\|A\hat{u} - b\|^2}{\|b\|^2} + (1-\alpha) \cdot \frac{\|\hat{u} - u_{\text{ref}}\|^2}{\|u_{\text{ref}}\|^2}$$

| α | Coefficient L² | Residual ‖Aû − b‖ |
|---|---|---|
| 0.000 | 3.68% | 0.95 |
| 0.001 | 4.12% | 1.16 |
| **0.005** | **22.0%** ← transition | 6.67 |
| 0.010 | 131% | 60.6 |
| 0.100 | 33.7% | 9.09 |
| 0.500 | 67.2% | 18.5 |
| 1.000 | 13 440% (diverged) | 19.9 |

**Finding**: A sharp phase transition occurs at $\alpha \approx 1/\kappa(A) 
\approx 8.6 \times 10^{-4}$, where $\kappa(A) \approx 1164$ is the condition 
number of the IGA stiffness matrix. Above this critical scale, the residual 
gradient $A^\top(A\hat{u} - b)$ amplifies high-frequency modes by a factor 
of $\kappa$, overwhelming the supervised signal. Pure residual training 
($\alpha = 1$) does not converge under any tested learning rate.

This finding extends the IgANets paper (Möller et al.), whose reported 
supervised weight of $\sim 10^7$ corresponds to $\alpha \approx 10^{-7}$ — 
two orders of magnitude below our critical scale, placing their operating 
point firmly in the supervised-dominated regime.

### E4 — Comparison with the Fourier Neural Operator

A 2D FNO (`modes = 12`, `width = 32`, 4 Fourier blocks, 593 265 parameters) 
is trained on the same 400 geometries using regular-grid samples.

| Metric | E1 (IgANets) | E4 (FNO) |
|---|---|---|
| Field-space relative L² | 3.09% | **2.26%** |
| Boundary violation | **1.51 × 10⁻⁴** | 1.37 × 10⁻³ |
| Parameter count | ~580k | 593k |
| Inference time (M4 CPU) | **0.062 ms** | 4.13 ms |
| Improvement over trivial baseline | 3.2× | **4.4×** |

**Finding**: FNO achieves modestly better field-space accuracy (27% relative 
improvement). E1 preserves boundary conditions an order of magnitude more 
accurately ($9\times$) and runs nearly two orders of magnitude faster 
($67\times$). The two methods occupy distinct regions of the 
accuracy–structure–speed trade-off space, suggesting they are 
**complementary rather than competing**.

## Building and running

### Requirements

- C++20 compiler (tested with AppleClang 17 on macOS)
- LibTorch 2.11+
- CMake 3.20+
- Python 3.11+ with PyTorch (for E4)

### Build C++ experiments

```bash
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make -j
```

### Run experiments

```bash
# 1. Generate dataset (~2 minutes, retry loop rejects folded geometries)
./docs/generate_data

# 2. Verify dataset
python3 docs/python/verify_dataset.py

# 3. Run IgANets experiments (each takes ~30 minutes on M4 CPU)
./docs/e1_coeff_prediction
./docs/e2_field_prediction
./docs/e3_alpha_sweep
./docs/e3_diagnostics

# 4. Run FNO baseline (~20 minutes on M4 CPU)
cd ../docs/python
python3 e4_train.py
python3 e4_eval.py
```

## Summary of contributions

1. **Identified and corrected a critical solver issue**: the upstream `EZSolver` 
   assembled the parameter-domain Laplacian, independent of geometry. After 
   patching with the Jacobian-based pull-back, $A(G)$ truly depends on $G$ 
   and the surrogate task becomes well-posed.

2. **E1 vs E2**: established that coefficient prediction and field-value 
   prediction give comparable accuracy under supervised training; the 
   structural advantage of E1 manifests in boundary preservation and in its 
   compatibility with residual-based losses.

3. **E3**: identified a sharp phase transition in mixed supervised/residual 
   training at $\alpha \approx 1/\kappa(A)$, with a complete mechanistic 
   explanation via gradient analysis. Pure residual training fails under any 
   learning rate. This extends and quantifies prior empirical observations 
   in the IgANets literature.

4. **E4**: characterised the trade-off space between IgANets and the Fourier 
   Neural Operator. FNO is better at accuracy (1.4×); IgANets is better at 
   boundary preservation (9×) and inference speed (67×). Neither is strictly 
   dominant, and the choice depends on deployment scenario.
